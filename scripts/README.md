# Scripts

This directory contains standalone execution scripts per `docs/03-architecture-and-modeling.md` §11 and `docs/07-ten-day-plan.md`:

- `build_all.py`: Full pipeline runner (ingest, align, features, train, calibrate, evaluate).
- `train.py`: Training script for baseline and fusion models.
- `export_static.py`: Export precomputed artefacts for static/offline dashboard hosting.
